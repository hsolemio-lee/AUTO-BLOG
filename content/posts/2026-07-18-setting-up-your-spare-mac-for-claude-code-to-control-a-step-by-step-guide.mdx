### "내가 쓰던 Mac으로 AI 제어 노드를?"

얼마 전, 작업 중에 문득 이런 생각이 들었어요. 집에 굴러다니는 스페어 Mac이 있는데, 이걸 그냥 두기 아깝다는 거죠. 마침 Claude Code라는 Anthropic의 AI 제어 플랫폼이 로컬 Mac도 제어 노드로 쓸 수 있다고 하니, 한번 직접 세팅해봤습니다. 프론트엔드 개발자인 제 입장에서, 어떻게 하면 내 Mac을 효과적으로 Claude Code 노드로 만들고, 내 앱과 연결할 수 있을지 공유해볼게요.

---

## macOS 최신 버전 유지가 왜 그렇게 중요할까?

일단, Claude Code 에이전트를 설치하려면 macOS가 최신 버전이어야 해요. 제가 테스트한 Mac은 macOS Ventura 13.4였는데, 이게 아니면 설치 스크립트가 제대로 작동하지 않거나, 네트워크 연결 문제, 권한 오류가 자주 발생하더라고요. 최신 OS가 아니면 보안 프로토콜이나 인증 토큰 처리에 문제가 생기기도 하고요.

실제로 설치 스크립트를 실행하기 전에 `sw_vers` 명령어로 OS 버전을 확인하는 게 필수입니다.

```bash
sw_vers
```

이후, Anthropic 공식 문서에서 제공하는 설치 스크립트를 터미널에 그대로 붙여넣으면 됩니다. 제 경우엔 아래처럼 했어요.

```bash
/bin/bash -c "$(curl -fsSL https://install.claude.code/agent-macos.sh)"
```

스크립트가 끝나면 API 키를 입력하라는 프롬프트가 뜨는데, 이 키는 Claude Code 플랫폼에서 발급받아야 하죠. API 키는 보안상 절대 노출하면 안 되니, 환경 변수로 관리하는 걸 추천합니다.

```
export CLAUDE_CODE_API_KEY="your_api_key_here"
```

이렇게 하면 Mac이 Claude Code 제어 노드로서 플랫폼과 인증 과정을 마치고, 네트워크에 연결됩니다.

> 참고로, 네트워크 방화벽 설정도 꼼꼼히 확인하세요. 특히 회사나 집 네트워크에서 포트 차단이 걸려 있으면 에이전트가 서버와 통신하지 못해요.

## 프론트엔드에서 Vercel AI SDK로 Claude Code 노드와 소통하기

프론트엔드 개발자라면 Claude Code 노드와 어떻게 통신할지 궁금할 텐데, 저는 Vercel AI SDK를 썼어요. 이 SDK는 인증, 요청 처리, 응답 수신을 상당히 간소화해 줍니다.

예를 들어, React 앱에서 다음과 같이 간단히 설정할 수 있죠.

```jsx
import { createAI } from 'vercel-ai-sdk';

const ai = createAI({
  apiKey: process.env.CLAUDE_CODE_API_KEY,
  model: 'claude-code',
});

async function fetchCodeCompletion(prompt) {
  try {
    const response = await ai.chat.completions.create({
      messages: [{ role: 'user', content: prompt }],
    });
    return response.choices[0].message.content;
  } catch (error) {
    console.error('Claude Code 요청 실패:', error);
    throw error;
  }
}

export default fetchCodeCompletion;
```

이 코드를 쓰면 프론트엔드에서 Claude Code 노드로 자연스럽게 요청을 보내고, AI가 생성한 코드를 받아올 수 있어요. 인증은 API 키 하나로 처리되고, 복잡한 네트워크 설정은 SDK가 알아서 해줍니다.

## 설치 중 흔히 만나는 문제와 해결법

제가 겪은 문제 중 가장 흔한 건 네트워크 방화벽 문제였어요. 특히 회사 VPN을 켠 상태에서 Mac 노드를 연결하려고 하면, 외부 서버와 통신이 막혀서 인증 오류가 나더라고요. 이럴 땐 VPN을 끄거나, 방화벽 설정에서 해당 포트를 열어줘야 했습니다.

또 한 가지는 API 키 인증 실패인데, 키를 복사할 때 공백이 들어가거나, 키가 만료된 경우 발생합니다. 키를 재발급받고, 환경 변수를 다시 설정하는 걸 추천합니다.

마지막으로, 에이전트 버전 불일치 문제도 있었는데, 설치 스크립트를 다시 실행해 최신 버전으로 업데이트하면 해결됐습니다.

이 모든 문제는 [Anthropic 공식 문서](https://docs.anthropic.com/en/docs/claude-code/overview)의 트러블슈팅 가이드가 큰 도움이 됐어요.

## 내 Mac을 AI 제어 노드로 쓰면서 느낀 점과 주의할 점

처음엔 "그냥 집에 있는 Mac 하나 연결하는 게 뭐 대수냐" 싶었는데, 실제로 해보니 네트워크 안정성, 인증 관리, 그리고 자원 최적화가 생각보다 까다롭더라고요. 특히 API 키 관리는 GitHub Copilot 문서에서 강조하는 것처럼 보안의 기본 중 기본입니다. 키가 노출되면 내 노드가 악용될 수 있으니, 꼭 안전한 저장소에 보관하세요.

그리고 Cursor 문서에서 말하는 것처럼, 로컬 머신 자원을 무작정 쓰는 게 아니라, 필요한 만큼만 할당하고, 네트워크 상태를 수시로 점검하는 게 중요합니다. 특히 Mac이 오래된 모델이면 CPU, 메모리 사용량을 모니터링하면서 부하가 과하지 않은지 살펴야 해요.

### 마무리하며: 직접 해보면 알게 되는 것들

스페어 Mac을 Claude Code 제어 노드로 만드는 건 생각보다 어렵지 않지만, "설치 스크립트 실행 -> API 키 입력 -> Vercel AI SDK로 통신"의 기본 흐름 뒤에 숨어있는 네트워크 문제, 인증 관리, 자원 최적화가 관건입니다. 

직접 해보면서 문제에 부딪히고 해결하는 과정이 가장 큰 공부였어요. 특히 프론트엔드 개발자가 AI 제어 노드를 직접 세팅해보면, AI와 앱 간 통신 구조를 훨씬 더 잘 이해할 수 있죠.

한 가지 팁을 드리자면, 설치 후에는 꼭 `claude-code agent status` 명령어로 에이전트 상태를 확인하세요. 에이전트가 제대로 동작하는지, 네트워크 연결은 정상인지 한눈에 볼 수 있습니다.

```bash
claude-code agent status
```

이걸로 "내 Mac이 AI 제어 노드로 잘 작동하는구나" 하는 확신을 가질 수 있답니다.
