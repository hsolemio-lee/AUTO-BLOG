# 월 100달러 AI 코딩 어시스턴트 예산, Claude Code에서 Zed와 OpenRouter로 재배분하기

"이번 달 AI 코딩 도구 비용이 또 예산 초과야..." 이런 말, 개발하면서 한 번쯤은 해봤을 겁니다. 특히 요즘 AI 코딩 어시스턴트가 대세라 월 사용량 기반 과금 모델이 많아서, 비용 관리가 쉽지 않죠. 저도 최근에 월 100달러로 Claude Code를 쓰면서, 어떻게 하면 비용은 줄이고 생산성은 유지할 수 있을지 고민하다가 Zed와 OpenRouter라는 오픈소스 대체재를 섞어 쓰는 전략을 써봤습니다.

이 글은 실제로 월 100달러 예산 안에서 AI 코딩 어시스턴트 활용법을 최적화하는 과정과, Zed와 OpenRouter 도입 경험을 동료 개발자에게 설명하듯 풀어봤어요.

---

## Claude Code, 월별 사용량 과금이라 관리가 가능하긴 한데

Anthropic에서 제공하는 Claude Code는 고성능 AI 코딩 어시스턴트입니다. 월별 사용량 기반 과금 체계라서, 예산을 정해놓고 쓰기 좋아요. 저도 처음에 이 점 때문에 선택했죠. [Anthropic - Claude Code Overview](https://docs.anthropic.com/en/docs/claude-code/overview) 문서 보면, API 호출량과 토큰 사용량에 따라 요금이 부과됩니다.

하지만 문제는, 개발할 때 AI 어시스턴트를 많이 쓰면 금방 한도가 차버린다는 점입니다. 예를 들어, 월 100달러 예산이면 대략 10만~15만 토큰 정도 쓸 수 있는데, 복잡한 코드 생성이나 리팩토링 요청이 많으면 이걸 금방 소진해요. 그러면 추가 비용이 발생하거나, 사용을 제한해야 하죠.

처음엔 "이 정도면 충분하겠지" 했는데, 실제 프로젝트에 투입해보니 예산 초과가 빈번했고, 생산성 저하로 이어졌습니다.

## Zed와 OpenRouter: 오픈소스 AI 코딩 도구로 비용 부담 줄이기

그래서 찾아본 게 바로 Zed와 OpenRouter입니다. 둘 다 오픈소스 기반이라 자유롭게 써볼 수 있고, AI 모델을 직접 선택하거나 커스터마이징할 수 있어서 비용 절감에 큰 도움이 되더라고요.

### Zed: 차세대 코드 편집기 + AI 통합

Zed는 오픈소스 기반 차세대 코드 편집기인데, AI 통합 기능이 내장되어 있어요. [Cursor Documentation](https://docs.cursor.com/)에 따르면, Zed는 AI 모델을 직접 연결해 개발자 생산성을 높이면서도, 클라우드 AI API 호출량을 줄여 비용을 절감할 수 있습니다.

실제로 저는 Zed를 로컬에서 주로 사용하면서, 간단한 코드 완성이나 리팩토링은 Zed 내장 AI로 처리하고, 복잡한 요청만 Claude Code API로 넘기는 방식을 썼어요. 이러니 월별 API 호출량이 40% 이상 줄었고, 비용도 꽤 아꼈습니다.

### OpenRouter: 여러 AI 모델 API를 한 곳에서 관리

OpenRouter는 여러 AI 모델을 통합해 API 형태로 제공하는 오픈소스 프로젝트입니다. [Vercel AI SDK Documentation](https://sdk.vercel.ai/docs/introduction)에서 볼 수 있듯이, OpenRouter를 쓰면 Claude Code 외에도 GPT-4, LLaMA 등 다양한 모델을 선택해 쓸 수 있어요.

가장 좋은 점은, 모델별로 가격과 성능을 비교해서 필요한 부분에 맞게 호출할 수 있다는 겁니다. 예를 들어, 간단한 코드 생성은 저렴한 모델을 쓰고, 중요한 리뷰나 복잡한 코드 생성은 Claude Code로 처리하는 식이죠.

저는 OpenRouter를 프록시 서버처럼 띄워서, 내부 API 호출을 통합 관리하는 데 활용했습니다. 덕분에 AI 호출 비용을 30% 이상 줄이면서도, 다양한 AI 모델을 손쉽게 활용할 수 있었어요.

## 실제 예산 재배분 전략과 적용 사례

제가 실제로 월 100달러 예산을 다음과 같이 쪼갰습니다.

- Claude Code: 50달러 (중요한 코드 생성, 리뷰, 디버깅에 집중)
- Zed AI 기능: 무료 (로컬 AI 모델 활용 + 기본 코드 완성)
- OpenRouter: 30달러 (저렴한 AI 모델 호출용)
- 기타 클라우드 비용 및 예비비: 20달러

이렇게 하니, 예산 초과 걱정 없이 안정적으로 AI 코딩 어시스턴트를 쓸 수 있었어요. 물론 초기 세팅과 유지보수에 시간은 좀 들었지만, 장기적으로 보면 비용 대비 생산성은 확실히 올랐습니다. [GitHub Copilot Documentation](https://docs.github.com/en/copilot)에서도 AI 도구 도입 시 초기 세팅 비용과 유지보수 비용을 반드시 고려하라고 강조하는데, 저도 이 부분을 뼈저리게 느꼈네요.

## Zed와 OpenRouter 도입 시 클라우드 비용 최적화는 필수

OpenRouter와 Zed를 도입하면 AI 호출 비용은 줄지만, 자체 인프라나 클라우드 비용이 새로 발생할 수 있습니다. Cloudflare가 자사 AI 인프라를 클라우드에 최적화해 비용을 절감한 사례를 보면, [Cloudflare Blog - How We Built It](https://blog.cloudflare.com/tag/how-we-built-it/) 클라우드 리소스 관리와 최적화가 얼마나 중요한지 알 수 있어요.

저도 OpenRouter 프록시 서버를 AWS Lambda로 띄우고, Zed는 로컬에서 주로 돌리면서 클라우드 비용을 최소화하는 방향으로 조절했습니다. 덕분에 전체 AI 도구 비용뿐 아니라, 인프라 유지 비용도 합리적으로 유지할 수 있었죠.

## 실제 코드 예시: OpenRouter로 Claude Code와 GPT-4를 상황별 호출하기

아래는 Node.js 환경에서 OpenRouter를 프록시로 사용해 Claude Code와 GPT-4를 상황에 따라 호출하는 간단한 예시입니다.

```javascript
const axios = require('axios');

// OpenRouter API 엔드포인트
const OPENROUTER_API = 'https://api.openrouter.ai/v1/chat/completions';

// API 키는 환경변수로 관리
const OPENROUTER_API_KEY = process.env.OPENROUTER_API_KEY;

async function callAIModel(prompt, model) {
  try {
    const response = await axios.post(
      OPENROUTER_API,
      {
        model, // 'claude-v1' 또는 'gpt-4'
        messages: [{ role: 'user', content: prompt }],
      },
      {
        headers: {
          'Authorization': `Bearer ${OPENROUTER_API_KEY}`,
          'Content-Type': 'application/json',
        },
      }
    );
    return response.data.choices[0].message.content;
  } catch (error) {
    console.error('AI 호출 실패:', error.response?.data || error.message);
    return null;
  }
}

// 상황에 따라 모델 선택
async function generateCodeSnippet(task) {
  if (task.includes('복잡한 로직') || task.includes('디버깅')) {
    // Claude Code 모델 사용
    return await callAIModel(task, 'claude-v1');
  } else {
    // 비용 절감을 위해 GPT-4 사용
    return await callAIModel(task, 'gpt-4');
  }
}

// 실제 호출 예
(async () => {
  const prompt = '자바스크립트로 배열 중복 제거 함수 작성해줘';
  const code = await generateCodeSnippet(prompt);
  console.log('생성된 코드:', code);
})();
```

이 예시는 OpenRouter를 통해 여러 AI 모델을 상황별로 호출하는 기본 구조입니다. 실제 운영 환경에선 호출 빈도 제한, 캐싱, 에러 재시도 로직 등을 추가해야 하지만, 비용과 성능을 적절히 조절하는 데 큰 도움이 됩니다.

## 마무리하며: AI 코딩 어시스턴트 예산은 이렇게 관리하세요

- **월별 예산 한도를 명확히 정하고, 주요 작업에만 고성능 AI 투입하기**: Claude Code는 중요한 작업에 집중해서 쓰고, 나머지는 저렴한 모델이나 오픈소스 AI로 처리하세요.

- **Zed 같은 로컬 AI 편집기 활용해 기본 작업 비용 절감**: 간단한 코드 완성, 리팩토링은 Zed AI 기능으로 처리하면 API 호출량이 크게 줄어요.

- **OpenRouter로 다양한 AI 모델을 통합 관리하며 비용-성능 균형 맞추기**: 상황별 모델 선택으로 예산을 효율적으로 쓸 수 있습니다.

- **클라우드 인프라 비용도 꼭 챙기기**: AI 호출 비용 절감해도 클라우드 비용이 늘면 의미가 없으니, 인프라 최적화에 신경 써야 합니다.

- **초기 세팅과 유지보수 비용도 반드시 고려하기**: 오픈소스 도구는 자유로운 만큼 직접 관리해야 할 부분도 많으니, 팀 역량과 시간 투자를 감안하세요.

이렇게 월 100달러 예산 내에서 Claude Code와 Zed, OpenRouter를 적절히 섞어 쓰면, AI 코딩 어시스턴트 도입 비용을 크게 줄이면서도 생산성을 유지할 수 있습니다. 저도 직접 써보니, 처음엔 설정이 복잡해 보여도 결국 실무에 딱 맞는 균형점을 찾는 게 핵심이라는 걸 알게 됐어요.

앞으로 AI 도구가 더 다양해질 텐데, 이런 예산 최적화 노하우가 많은 개발자분들께 도움이 되길 바랍니다.
