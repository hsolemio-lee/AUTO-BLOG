## "이 영상, 어떻게 자동으로 편집하지?" 고민하다 마주친 agentic 백엔드

최근에 "Launch HN: Cardboard (YC W26) – Agentic video editor" 글을 보고, 자동화된 비디오 편집 백엔드를 어떻게 구현했을지 궁금해졌어요. 단순히 AI가 영상 자르고 붙이는 걸 넘어서, 자연어 명령을 해석해 복잡한 편집 워크플로우를 실시간으로 처리한다는 점에서 상당히 흥미로웠죠.

실제로 이런 시스템을 만들려면 다양한 AI 모델을 조합하고, API 호출을 효율적으로 관리해야 하는데, 이 부분이 생각보다 까다롭습니다. 오늘은 제가 Cardboard 같은 agentic 비디오 편집 백엔드 구축 경험을 공유하며, OpenAI API와 Anthropic Claude Code, 그리고 Cursor 같은 도구를 어떻게 활용할 수 있는지 이야기해볼게요.

---

## OpenAI API가 agentic 비디오 편집에서 핵심인 이유

Cardboard가 비디오 편집 작업을 자동화하는 데 OpenAI API를 적극 활용하는 건 놀랍지 않아요. OpenAI API는 자연어 처리부터 이미지, 음성, 코드 생성까지 다양한 기능을 제공하니까요. 특히 비디오 편집 명령을 자연어로 받으면, 내부적으로 여러 단계를 거쳐 편집 명령을 구체적인 작업으로 변환하는 과정에서 OpenAI의 GPT 모델이 큰 역할을 합니다.

예를 들어, "이 부분은 5초만 남기고 나머지는 삭제해줘"라는 명령을 받으면, API가 이를 해석해 정확한 타임코드를 산출하고, 후속 작업을 위한 JSON 명세로 변환하는 식이죠. 이런 자동화 덕분에 사용자 경험이 훨씬 직관적이고 빠릅니다.

OpenAI API 문서에 따르면, 다양한 편집 작업을 위한 커스텀 프롬프트 설계와 API 호출 조합이 가능해 복잡한 워크플로우를 효과적으로 관리할 수 있습니다[OpenAI API Documentation](https://platform.openai.com/docs/overview).

## Anthropic Claude Code로 실시간 비디오 편집 작업을 어떻게 처리할까?

Cardboard가 실시간 처리와 확장성 측면에서 Anthropic의 Claude Code를 선택한 것도 인상적입니다. Claude Code는 자연어 명령을 코드로 변환하는 데 특화되어 있는데, agentic 시스템에서는 이게 곧바로 비디오 편집 명령을 실행 가능한 스크립트로 바꾸는 역할을 합니다.

실제로 비디오 편집은 프레임 단위로 세밀한 작업이 필요한데, Claude Code가 제공하는 정교한 코드 생성 능력 덕분에 실시간으로 명령을 해석하고 즉시 처리할 수 있죠. 예를 들어, 사용자가 "인트로 부분에 자막을 넣고, 배경음악 볼륨을 30% 줄여줘"라고 하면, Claude Code가 이를 ffmpeg 명령어나 내부 편집 스크립트로 변환합니다.

이 과정에서 자연어와 코드 변환의 정확도가 높아야 실시간 편집이 끊기지 않고 부드럽게 진행되는데, Anthropic 문서에서도 Claude Code가 이런 agentic 워크플로우에 최적화되어 있다고 명시하고 있습니다[Anthropic - Claude Code Overview](https://docs.anthropic.com/en/docs/claude-code/overview).

## Cursor로 API 오케스트레이션, 복잡한 AI 모델 통합을 쉽게

Cardboard 같은 서비스는 단일 AI 모델만 쓰지 않고, OpenAI, Anthropic, 자체 서비스 등 여러 API를 조합해야 합니다. 이때 API 호출 순서와 데이터 흐름을 관리하는 게 백엔드의 핵심 난제인데, Cursor 플랫폼이 이 문제를 상당히 깔끔하게 해결해줍니다.

Cursor는 프론트엔드와 백엔드 간 API 오케스트레이션을 간소화하는데, 여러 AI 모델과 서비스의 호출을 하나의 플로우로 묶어 관리할 수 있어요. 예를 들어, 영상 분석 → 편집 명령 생성 → 편집 스크립트 실행 → 결과 반환까지 복잡한 단계가 있는데, Cursor를 쓰면 이걸 코드 몇 줄로 정의하고 상태를 추적할 수 있습니다.

실제로 Cursor 문서에서는 agentic 비디오 편집기에서 다양한 AI 서비스 통합을 원활하게 지원한다고 소개합니다. 이 덕분에 개발자는 비즈니스 로직에만 집중할 수 있고, API 호출 실패나 재시도 로직도 Cursor가 알아서 처리해줘요[Cursor Documentation](https://docs.cursor.com/).

## Vercel AI SDK로 배포와 실시간 확장성 잡기

실시간 비디오 편집은 요청이 몰릴 때 백엔드가 버티는 게 관건입니다. Cardboard는 Vercel AI SDK를 활용해 클라우드 환경에서 agentic 애플리케이션을 빠르게 배포하고, 필요에 따라 실시간으로 확장합니다.

Vercel AI SDK는 프론트엔드와 백엔드 간 신속한 데이터 교환과 API 호출 최적화에 강점이 있는데, 덕분에 사용자 요청에 대한 응답 속도가 빠르고, 서버 부하가 급증해도 자동으로 인스턴스를 늘려 서비스 안정성을 확보할 수 있죠.

실제로 Vercel AI SDK를 활용하면, Next.js 같은 프레임워크와도 쉽게 통합되어, 프론트엔드에서 편집 명령을 바로 백엔드로 전달하고 결과를 실시간으로 렌더링하는 구조를 만들 수 있습니다[ Vercel AI SDK Documentation](https://sdk.vercel.ai/docs/introduction).

## GitHub Copilot으로 agentic 백엔드 코드 작성과 유지보수 가속화

복잡한 비디오 편집 워크플로우를 코드로 구현하다 보면, 반복되는 API 호출 패턴이나 에러 핸들링 코드가 많아지는데, GitHub Copilot이 큰 도움이 됩니다. Copilot은 코드 자동 완성뿐 아니라, 문맥에 맞는 코드 스니펫을 제안해줘서 빠른 프로토타이핑과 유지보수가 가능하죠.

예를 들어, OpenAI API를 호출하는 비동기 함수 작성 시, Copilot이 인증 토큰 처리, 에러 리트라이 로직까지 자동 완성해주니 개발 생산성이 눈에 띄게 올라갑니다. 물론 Copilot 제안 코드는 항상 리뷰가 필요하지만, 초기 개발 속도를 확실히 높여줍니다[GitHub Copilot Documentation](https://docs.github.com/en/copilot).

## Anthropic의 프롬프트 엔지니어링 가이드로 API 호출 최적화하기

agentic 시스템에서 자연어 명령을 API 호출로 바꾸는 과정은 단순하지 않습니다. 프롬프트 설계가 잘못되면 불필요한 API 호출이 많아지고, 처리 속도와 정확도가 떨어지거든요. Anthropic의 프롬프트 엔지니어링 가이드는 이런 문제를 줄이는 데 큰 도움이 됩니다.

예를 들어, 비디오 자막 생성 명령을 최적화할 때, "자막을 10초 단위로 나눠서 생성" 같은 구체적인 조건을 프롬프트에 넣으면, API가 더 정확하고 빠르게 응답합니다. 이런 최적화는 실시간 편집 워크플로우에서 지연 시간을 줄이고, 비용도 절감하는 효과가 있어요[Anthropic - Prompt Engineering Guide](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview).

## 실전! OpenAI API와 Claude Code를 함께 쓰는 간단한 예시

아래는 자연어 명령을 받아 OpenAI API로 편집 계획을 생성하고, Claude Code로 편집 명령 스크립트를 만드는 간단한 Node.js 예시입니다.

```javascript
const { Configuration, OpenAIApi } = require('openai');
const axios = require('axios');

const openai = new OpenAIApi(new Configuration({ apiKey: process.env.OPENAI_API_KEY }));

async function generateEditPlan(naturalCommand) {
  // 1. OpenAI GPT로 편집 계획 생성
  const planResponse = await openai.createChatCompletion({
    model: 'gpt-4',
    messages: [
      { role: 'system', content: '비디오 편집 계획을 JSON으로 만들어줘.' },
      { role: 'user', content: naturalCommand }
    ],
  });
  const plan = JSON.parse(planResponse.data.choices[0].message.content);

  // 2. Anthropic Claude Code API 호출해서 편집 스크립트 생성
  const claudeResponse = await axios.post('https://api.anthropic.com/v1/claude-code', {
    prompt: `Create ffmpeg script for this plan: ${JSON.stringify(plan)}`,
  }, {
    headers: { 'x-api-key': process.env.ANTHROPIC_API_KEY }
  });

  return claudeResponse.data.script;
}

// 사용 예시
(async () => {
  const naturalCommand = '인트로 5초만 남기고 나머지는 삭제해줘';
  const script = await generateEditPlan(naturalCommand);
  console.log('생성된 편집 스크립트:', script);
})();
```

이 코드는 프롬프트 설계, API 호출 순서, 그리고 결과를 실제 편집 스크립트로 변환하는 과정을 단순화한 예입니다. 실제 서비스에서는 오류 처리, 캐싱, 비동기 워크플로우 관리가 더 필요하겠죠.

## 마무리하며: agentic 비디오 편집 백엔드, 꼭 기억할 점

- **API 오케스트레이션이 핵심**: 여러 AI 모델과 API를 효과적으로 조합하고 관리하는 게 서비스 안정성과 확장성의 기본입니다.
- **실시간 처리에 최적화된 도구 활용**: Anthropic Claude Code 같은 자연어→코드 변환 모델은 실시간 편집 명령 실행에 필수적입니다.
- **프롬프트 설계에 투자하라**: 프롬프트를 잘 다듬으면 API 호출 비용과 지연 시간을 크게 줄일 수 있습니다.
- **클라우드 배포와 확장성 고려**: Vercel AI SDK 같은 플랫폼을 이용하면 서비스 확장과 유지보수가 훨씬 수월해집니다.
- **개발 생산성도 무시하지 말자**: GitHub Copilot 같은 도구를 적극 활용해 빠른 프로토타입과 안정적인 코드베이스를 유지하세요.

처음엔 agentic 비디오 편집 백엔드가 너무 복잡해 보여도, 적절한 AI 모델 조합과 API 오케스트레이션으로 충분히 현실적인 서비스가 된다는 걸 Cardboard가 보여줬습니다. 우리도 이런 흐름을 참고해 다음 프로젝트에 적용해보면 좋겠네요.
