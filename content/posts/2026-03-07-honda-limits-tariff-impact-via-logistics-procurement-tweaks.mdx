## 관세가 갑자기 오르면 엔지니어는 어떻게 대응할까?

최근 글로벌 공급망이 요동치면서 관세 부담이 기업 비용에 큰 영향을 미치고 있죠. 자동차 업계 대표주자인 Honda도 예외는 아닙니다. 관세가 올라가면 부품 구매 비용은 물론, 물류비용까지 덩달아 상승하는데요. 이럴 때 단순히 가격을 올리는 대신, 물류 경로와 조달 방식을 바꿔서 관세 충격을 완화하는 전략이 필요합니다.

내가 직접 SCM 시스템을 다루는 입장에서, Honda가 어떻게 물류와 조달 프로세스를 조정했는지, 그리고 우리가 개발하는 SCM 시스템에선 어떤 기능과 최적화가 가능한지 이야기해볼게요.


## Honda가 관세 충격을 줄이기 위해 실제로 바꾼 것들

Honda는 관세가 부품 단가에 미치는 영향을 줄이기 위해 크게 두 가지를 조정했습니다.

- **물류 경로 재설계**: 관세가 높은 국가에서 직접 수입하는 대신, 관세가 낮거나 무관세 지역을 경유하는 우회 경로를 활용.
- **조달처 다변화 및 계약 조건 변경**: 특정 국가에 집중된 조달처를 분산시키고, 비용 상승분을 최소화할 수 있는 장기 계약과 협상 전략을 도입.

이 과정에서 물류와 조달 데이터를 실시간으로 모니터링할 수 있는 SCM 시스템이 핵심 역할을 했죠. 단순히 재고만 관리하는 게 아니라, 관세 변동에 따른 비용 시뮬레이션과 대체 경로 추천까지 자동화했습니다.


## Dynamics 365 SCM으로 관세 영향에 대응하는 법

Microsoft의 Dynamics 365 Supply Chain Management는 AI와 데이터 분석을 활용해 공급망 가시성을 높이고, 비용 효율적인 조달과 물류 경로 최적화를 돕습니다. 예를 들어, 관세율이 높은 국가에서 부품을 수입할 때, 시스템은 대체 공급처와 경로를 실시간으로 추천해주죠.

```typescript
// TypeScript로 작성한 간단한 관세 영향 시뮬레이션 예시
interface Supplier {
  name: string;
  country: string;
  tariffRate: number; // 관세율(%)
  baseCost: number; // 기본 단가
}

function calculateTotalCost(supplier: Supplier, quantity: number): number {
  const tariffCost = supplier.baseCost * (supplier.tariffRate / 100);
  return (supplier.baseCost + tariffCost) * quantity;
}

const suppliers: Supplier[] = [
  { name: 'A사', country: '국가A', tariffRate: 10, baseCost: 100 },
  { name: 'B사', country: '국가B', tariffRate: 2, baseCost: 110 },
];

const quantity = 1000;

suppliers.forEach(supplier => {
  console.log(`${supplier.name} 총 비용: $${calculateTotalCost(supplier, quantity)}`);
});
```

이런 간단한 계산부터 시작해, Dynamics 365는 복잡한 시나리오도 AI가 분석해주니, 우리가 직접 수십 가지 케이스를 고민할 필요가 줄어듭니다. 관세 변동에 맞춰 물류 경로를 자동으로 재설계하는 기능도 있어, 실무에서 큰 도움이 됩니다.[Microsoft Learn - Dynamics 365 Supply Chain Management](https://learn.microsoft.com/en-us/dynamics365/supply-chain/)


## Oracle SCM 클라우드가 조달 자동화로 비용 부담 줄이는 법

Oracle의 SCM 및 제조 클라우드 솔루션은 조달 프로세스 자동화와 실시간 재고 관리에 강점이 있습니다. 관세가 오르면 부품 주문 시점과 수량을 최적화해 비용 상승을 최소화하는데요.

예를 들어, 관세가 갑자기 15%에서 25%로 오를 때, Oracle SCM은 실시간 재고 데이터를 바탕으로 주문 주기를 조정하거나 대체 부품을 추천할 수 있습니다. 이 과정은 전적으로 자동화되어 있어, 조달 담당자가 일일이 수작업으로 계산하지 않아도 되죠.[Oracle Docs - SCM and Manufacturing](https://docs.oracle.com/en/cloud/saas/supply-chain-and-manufacturing/)


## SAP SCM으로 복잡한 관세 환경에서 유연한 조달 전략 세우기

SAP SCM은 통합 물류 관리와 공급자 협업 기능을 제공합니다. 관세가 복잡하게 얽힌 글로벌 시장에서, SAP 시스템은 각 공급자별 관세 적용 현황을 관리하고, 협업 포털을 통해 신속하게 계약 조건을 재조정할 수 있게 도와줍니다.

이 덕분에 기업은 비용과 리스크를 동시에 관리하며, 관세 변동에 따른 공급망 충격을 최소화할 수 있습니다. 예를 들어, 특정 부품에 대해 관세가 급등하면 SAP SCM은 관련 공급자와의 계약을 자동으로 검토하고, 대체 공급자 정보를 빠르게 공유하는 식이죠.[SAP Help Portal - Supply Chain Management](https://help.sap.com/docs/SAP_SUPPLY_CHAIN_MANAGEMENT)


## 직접 SCM 시스템에 적용해본 관세 영향 완화 기능 아이디어

내가 직접 SCM 백엔드 시스템을 설계할 때 고려한 점은 다음과 같습니다.

- **관세율 데이터 실시간 반영**: 외부 관세 데이터 API와 연동해 최신 관세율을 주기적으로 업데이트
- **비용 시뮬레이션 API**: 특정 부품과 공급처, 물류 경로를 입력하면 예상 총비용을 계산해주는 서비스
- **대체 경로 및 공급처 추천 엔진**: 비용, 납기, 관세 등을 종합해 최적 대안을 추천

아래는 비용 시뮬레이션 API의 간단한 예시 코드입니다.

```typescript
interface ProcurementRequest {
  partId: string;
  supplierId: string;
  quantity: number;
}

interface CostEstimate {
  totalCost: number;
  breakdown: {
    baseCost: number;
    tariffCost: number;
    logisticsCost: number;
  };
}

// 실제로는 DB 조회, 외부 API 호출 포함
async function estimateCost(request: ProcurementRequest): Promise<CostEstimate> {
  // 예시 데이터
  const baseCost = 100; // 부품 단가
  const tariffRate = 12; // %
  const logisticsCost = 15; // 고정 물류비

  const tariffCost = baseCost * (tariffRate / 100);
  const totalCost = (baseCost + tariffCost + logisticsCost) * request.quantity;

  return {
    totalCost,
    breakdown: {
      baseCost: baseCost * request.quantity,
      tariffCost: tariffCost * request.quantity,
      logisticsCost: logisticsCost * request.quantity,
    },
  };
}
```

이런 API를 기반으로 UI에서 실시간으로 비용 변화를 보여주고, 대체 경로나 공급처를 추천하는 기능을 붙이면, 조달 담당자들이 관세 변동에 빠르게 대응할 수 있습니다.


## 관세 대응 최적화, 완벽한 해법은 없다

물론, 관세 최적화는 쉽지 않습니다. 우회 경로를 쓰면 배송 시간이 길어지고, 조달처를 늘리면 관리 복잡도가 올라가죠. 시스템이 아무리 좋아도, 결국 비즈니스 상황과 협상력이 관건입니다.

그래도 SCM 시스템에서 관세 데이터를 적극 반영하고, AI 기반 시뮬레이션과 추천 기능을 넣으면, 의사결정 속도와 정확도가 크게 올라갑니다. Honda 사례처럼, 관세 충격을 시스템 차원에서 완화하는 시도는 앞으로 더 중요해질 겁니다.
